# 发布流程

## 发布顺序

1. 运行 Python 和 TypeScript 测试。
2. 运行 Python `twine check` 与 TypeScript `npm publish --dry-run`。
3. 推送 GitHub 仓库。
4. 发布 npm `@oworker/aclip`。
5. 发布 PyPI `oworker-aclip`。
6. 用独立安装命令验证注册中心可用。

## npm

```powershell
cd sdk\typescript
npm install
npm run release:check
$env:NPM_TOKEN = "<token>"
npm run release:publish
```

发布后验证：

```powershell
npm view @oworker/aclip version
node -e "import('@oworker/aclip').then(m=>console.log(Boolean(m.AclipApp)))"
```

## PyPI

```powershell
cd sdk\python
python -m pip install -e ".[dev]"
python scripts\publish.py check
$env:PYPI_TOKEN = "<token>"
python scripts\publish.py publish
```

发布后验证：

```powershell
python -m pip install oworker-aclip
python -c "from aclip import AclipApp; print(AclipApp.__name__)"
```

## GitHub

仓库名：`oworker-dev/oworker-aclip`。

首次发布时应包含迁移说明、完整源码、schema、测试、当前文档包和 `legacy/` 原始归档。不要提交本地凭证、虚拟环境或构建输出。
