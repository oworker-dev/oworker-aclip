# 迁移说明

## 迁移范围

本次迁移来自 `rendo-archived/aclip`，保留内容包括：

- 根 README 的历史版本，保存在 `legacy/rendo-README.md`。
- 原始协议和产品文档，保存在 `legacy/rendo-docs/`。
- `schema/` 下的全部 JSON Schema。
- Python SDK、测试、demo CLI 和 Skill 示例。
- TypeScript SDK、测试、demo CLI 和 Skill 示例。

清理内容只限生成物和本地环境，包括 `.git`、`.venv`、`.pytest_cache`、`node_modules`、`build`、`dist`、`*.egg-info` 和 PyInstaller spec。

## OWorker 化变更

- npm 包名：`@oworker/aclip`。
- PyPI 包名：`oworker-aclip`。
- GitHub 仓库：`oworker-dev/oworker-aclip`。
- 文档包：中文优先，面向外部用户与后续维护者。
- 发布脚本：Python 只发布 canonical 包，不自动发布历史短名 alias。

## 保留兼容

- Python import path 仍为 `aclip`。
- 协议版本仍为 `aclip/0.1`。
- SDK 公开 API 语义保持与 Rendo `0.3.4` 对齐。
- 示例 CLI 名称保留 `aclip-demo-notes`。

## 原始文档如何使用

`legacy/rendo-docs/` 是完整历史归档，不作为当前公开入口。维护者需要追溯设计理由时优先查看：

- `PRD.md`
- `SPEC.md`
- `ARCHITECTURE.md`
- `CONFORMANCE.md`
- `AUTH-STANDARD.md`
- `DOCTOR-CONTROL-PLANE.md`
- `SKILL-EXPORT-HOOKS-VPD.md`
- `WORKFLOW-HOOKS-AND-SKILL-EXPORT.md`

当前用户与维护文档以 `docs/` 为准。
