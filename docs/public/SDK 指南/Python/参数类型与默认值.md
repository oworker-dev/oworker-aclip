# Python 参数类型与默认值

Python SDK 有两种参数声明方式。

## 方式一：函数签名自动推断

```python
def create_note(title: str, body: str, priority: int = 3, pinned: bool = False) -> dict:
    """Create a note.

    Args:
        title: Note title.
        body: Note body.
        priority: Priority from 1 to 5.
        pinned: Whether to pin the note.
    """
    return {
        "title": title,
        "body": body,
        "priority": priority,
        "pinned": pinned,
    }
```

推断结果：

- `str` -> string 参数
- `int` -> integer 参数
- `bool` -> boolean flag
- 没有默认值 -> required
- 有默认值 -> optional
- docstring `Args:` -> 参数说明

运行：

```bash
python cli.py note create --title hello --body world --priority 5 --pinned
```

## 方式二：显式 `ArgumentSpec`

需要控制 flag、choices、multiple、position 时使用 `ArgumentSpec`：

```python
from aclip import ArgumentSpec

app.command(
    "search",
    summary="Search notes",
    description="Search notes by query and tag.",
    arguments=[
        ArgumentSpec(
            name="query",
            kind="string",
            description="Search query.",
            required=True,
            positional=True,
        ),
        ArgumentSpec(
            name="tag",
            kind="string",
            description="Tag filter.",
            flags=("--tag", "-t"),
            multiple=True,
        ),
        ArgumentSpec(
            name="format",
            kind="string",
            description="Output format.",
            choices=["json", "text"],
            default="json",
        ),
    ],
    examples=["notes search hello --tag work --tag urgent --format json"],
    handler=search_notes,
)
```

运行：

```bash
python cli.py search hello --tag work --tag urgent --format json
```

## 参数字段

- `name`: handler payload 里的字段名。
- `kind`: `"string"`、`"integer"`、`"boolean"`。
- `description`: 帮助和 manifest 里的参数说明。
- `required`: 是否必填。
- `flag`: 单个 flag，例如 `"--store"`。
- `flags`: 多个别名，例如 `("--store", "-s")`。
- `positional`: 是否位置参数。
- `default`: 默认值。
- `choices`: 可选值。
- `multiple`: 是否允许多次传入。
- `env_var`: 记录参数可从哪个环境变量读取，进入 manifest。

不要同时设置 `flag` 和 `flags`。flag 必须以 `-` 开头，且不能覆盖 `--help` 或 `-h`。
