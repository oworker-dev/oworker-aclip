# Python 命令与命令组

## 根命令

根命令直接挂在 app 上：

```python
def status() -> dict:
    """Show current status."""
    return {"ok": True}


app.command(
    "status",
    handler=status,
    examples=["notes status"],
)
```

运行：

```bash
python cli.py status
```

## 命令组

多命令 CLI 应优先使用命令组：

```python
note = app.group(
    "note",
    summary="Manage notes",
    description="Create and inspect notes.",
)
```

在组里加命令：

```python
def create_note(title: str, body: str) -> dict:
    """Create a note.

    Args:
        title: Note title.
        body: Note body.
    """
    return {"note": {"title": title, "body": body}}


note.command(
    "create",
    handler=create_note,
    examples=["notes note create --title hello --body world"],
)
```

运行：

```bash
python cli.py note create --title hello --body world
```

## 嵌套命令组

`CommandGroupBuilder.group(...)` 可以继续创建子组：

```python
project = app.group(
    "project",
    summary="Manage projects",
    description="Create and inspect projects.",
)

project.group(
    "member",
    summary="Manage project members",
    description="Invite and remove members.",
).command(
    "invite",
    handler=invite_member,
    examples=["work project member invite --email dev@example.com"],
)
```

## 命令必须写什么

每个命令至少需要：

- command name
- handler
- summary 或可推断 docstring summary
- description 或可推断 docstring description
- 至少一个 example

SDK 会校验命令路径不能重复、命令不能和命令组同名、参数不能覆盖保留 `--help` / `-h`。

## 帮助命令

ACLIP Python SDK 支持普通帮助路径：

```bash
python cli.py --help
python cli.py note --help
python cli.py note create --help
python cli.py help --all
```

`--help` / `-h` 是协议保留的帮助入口，不要把它作为业务参数。
