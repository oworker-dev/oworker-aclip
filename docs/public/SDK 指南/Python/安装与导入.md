# Python 安装与导入

## 安装

```bash
pip install oworker-aclip
```

发布包名是 `oworker-aclip`，代码导入路径是 `aclip`：

```python
from aclip import AclipApp, run_cli
```

这是有意保留的兼容策略。`aclip` 是协议和 SDK 的代码命名空间，不随 OWorker 包名迁移而改变。

## 最小文件结构

```text
notes-cli/
  app.py
```

`app.py`：

```python
from aclip import AclipApp, run_cli


def create_app() -> AclipApp:
    app = AclipApp(
        name="notes",
        version="0.1.0",
        summary="A minimal notes CLI.",
        description="Create and list notes.",
    )
    return app


if __name__ == "__main__":
    run_cli(create_app)
```

运行：

```bash
python app.py --help
python app.py --version
```

## `run_cli` 可以接收什么

`run_cli` 是 `cli_main` 的别名，可以接收：

- `AclipApp` 实例：`run_cli(app)`
- 无参 factory：`run_cli(create_app)`
- import target 字符串：`run_cli("notes_app:create_app")`

推荐在 CLI 入口里传 factory，这样 app 在进程启动时再创建。

## Python SDK 常用导入

```python
from aclip import (
    AclipApp,
    ArgumentSpec,
    CredentialSpec,
    AuthCommandConfig,
    AuthStatus,
    DoctorCheck,
    build_auth_control_plane,
    build_doctor_control_plane,
    build_cli,
    export_skills,
    run_cli,
)
```

注意：Python SDK 不导出 `string_argument`、`integer_argument`、`boolean_argument` helper。Python 的推荐路径是：

- 用函数签名和 docstring 自动推断参数。
- 需要完全控制时直接写 `ArgumentSpec`。
