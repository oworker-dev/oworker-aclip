# Python 输出与错误

## 成功输出

handler 的返回值决定 stdout。

```python
def status() -> dict:
    return {"status": "ok"}
```

输出 JSON：

```json
{"status":"ok"}
```

规则：

- 返回 `None`: 不输出。
- 返回 `str`: 原样输出，SDK 会补末尾换行。
- 返回 dict/list/number/bool: 输出 JSON。

ACLIP 不强制成功输出套统一 envelope。CLI 作者可以按自己的产品体验决定输出格式。

## 错误输出

SDK 捕获参数解析错误和 handler 异常，输出结构化 error envelope 到 stderr。

参数错误示例：

```json
{
  "command": "note create",
  "error": {
    "code": "validation_error",
    "message": "invalid command usage"
  },
  "ok": false,
  "protocol": "aclip/0.1",
  "type": "error"
}
```

handler 抛异常会输出 `execution_error`。

## 退出码

- `0`: 成功或帮助输出。
- `1`: handler 执行异常。
- `2`: 参数、帮助路径或版本配置错误。

## 手动构造 envelope

需要在自己的 handler 中返回标准结果时，可以使用：

```python
from aclip.runtime import error_envelope, result_envelope
```

但常规业务命令不必手动包 envelope。只有你需要和上层系统约定固定结果结构时才这么做。
