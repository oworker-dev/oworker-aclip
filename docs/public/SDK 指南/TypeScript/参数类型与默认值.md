# TypeScript 参数类型与默认值

TypeScript SDK 使用显式 helper 声明参数。

## 基本类型

```ts
import {
  booleanArgument,
  integerArgument,
  stringArgument
} from "@oworker/aclip";

const args = [
  stringArgument("title", {
    required: true,
    description: "Note title."
  }),
  integerArgument("priority", {
    description: "Priority from 1 to 5.",
    defaultValue: 3
  }),
  booleanArgument("pinned", {
    description: "Pin the note."
  })
];
```

运行：

```bash
notes note create --title hello --priority 5 --pinned
```

## 参数字段

- `name`: handler payload 里的字段名。
- `description`: 帮助和 manifest 里的参数说明。
- `required`: 是否必填。
- `flag`: 单个 flag，例如 `"--store"`。
- `flags`: 多个别名，例如 `["--store", "-s"]`。
- `positional`: 是否位置参数。
- `defaultValue`: 默认值。
- `choices`: 可选值。
- `multiple`: 是否允许多次传入。
- `envVar`: 记录参数可从哪个环境变量读取，进入 manifest。

## 自定义 flags

```ts
stringArgument("store", {
  flags: ["--store", "-s"],
  description: "Path to local store.",
  defaultValue: ".notes.json"
})
```

不要同时设置 `flag` 和 `flags`。flag 必须以 `-` 开头，且不能覆盖 `--help` 或 `-h`。

## choices

```ts
stringArgument("format", {
  description: "Output format.",
  choices: ["json", "text"],
  defaultValue: "json"
})
```

## 多值参数

```ts
stringArgument("tag", {
  flags: ["--tag", "-t"],
  description: "Tag filter.",
  multiple: true
})
```

运行：

```bash
notes search --tag work --tag urgent
```

## 位置参数

```ts
stringArgument("query", {
  positional: true,
  required: true,
  description: "Search query."
})
```

运行：

```bash
notes search hello
```
