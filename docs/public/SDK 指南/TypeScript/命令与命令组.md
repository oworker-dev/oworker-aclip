# TypeScript 命令与命令组

## 根命令

```ts
app.command("status", {
  summary: "Show status",
  description: "Show current status.",
  examples: ["notes status"],
  handler: () => ({ ok: true })
});
```

运行：

```bash
node --import tsx ./src/cli.ts status
```

## 命令组

```ts
const note = app.group("note", {
  summary: "Manage notes",
  description: "Create and inspect notes."
});
```

在组里加命令：

```ts
import { stringArgument } from "@oworker/aclip";

note.command("create", {
  summary: "Create a note",
  description: "Create a note.",
  arguments: [
    stringArgument("title", { required: true, description: "Note title." }),
    stringArgument("body", { required: true, description: "Note body." })
  ],
  examples: ["notes note create --title hello --body world"],
  handler: ({ title, body }) => ({ note: { title, body } })
});
```

运行：

```bash
node --import tsx ./src/cli.ts note create --title hello --body world
```

## 嵌套命令组

```ts
app.group("project", {
  summary: "Manage projects",
  description: "Create and inspect projects."
}).group("member", {
  summary: "Manage members",
  description: "Invite and remove members."
}).command("invite", {
  summary: "Invite member",
  description: "Invite a member by email.",
  arguments: [stringArgument("email", { required: true, description: "Email address." })],
  examples: ["work project member invite --email dev@example.com"],
  handler: ({ email }) => ({ invited: email })
});
```

## 命令必须写什么

每个命令需要：

- command name
- `summary`
- `description`
- `examples`
- `handler`

SDK 会校验命令路径不能重复、命令不能和命令组同名、参数不能覆盖保留 `--help` / `-h`。

## 帮助命令

```bash
node --import tsx ./src/cli.ts --help
node --import tsx ./src/cli.ts note --help
node --import tsx ./src/cli.ts note create --help
node --import tsx ./src/cli.ts help --all
```

`--help` / `-h` 是协议保留帮助入口，不要作为业务参数。
