# TypeScript 安装与导入

## 安装

```bash
npm install @oworker/aclip
```

开发时通常还需要 `tsx` 直接运行 `.ts` 文件：

```bash
npm install -D tsx
```

导入：

```ts
import { AclipApp, runCli } from "@oworker/aclip";
```

## 最小文件结构

```text
notes-cli/
  package.json
  src/
    app.ts
    cli.ts
```

`src/app.ts`：

```ts
import { AclipApp } from "@oworker/aclip";

export function createApp() {
  return new AclipApp({
    name: "notes",
    version: "0.1.0",
    summary: "A minimal notes CLI.",
    description: "Create and list notes."
  });
}

export const app = createApp();
```

`src/cli.ts`：

```ts
import { runCli } from "@oworker/aclip";
import { createApp } from "./app.js";

void runCli(createApp);
```

运行：

```bash
node --import tsx ./src/cli.ts --help
node --import tsx ./src/cli.ts --version
```

## `runCli` 可以接收什么

`runCli` 是 `cliMain` 的别名，可以接收：

- `AclipApp` 实例：`runCli(app)`
- 同步 factory：`runCli(createApp)`
- 异步 factory：`runCli(async () => app)`
- import target 字符串：`runCli("./src/app.ts:createApp")`

推荐在 CLI 入口里传 factory，方便后续打包。
