# TypeScript 输出与错误

## 成功输出

handler 的返回值决定 stdout：

```ts
app.command("status", {
  summary: "Show status",
  description: "Show current status.",
  examples: ["notes status"],
  handler: () => ({ status: "ok" })
});
```

规则：

- 返回 `undefined` / `null`: 不输出。
- 返回 `string`: 原样输出，SDK 会补末尾换行。
- 返回 object/array/number/boolean: 输出 JSON。

ACLIP 不强制成功输出套统一 envelope。CLI 作者可以按自己的产品体验决定输出格式。

## 错误输出

参数解析错误和 handler 异常会输出结构化 error envelope 到 stderr。

```json
{
  "protocol": "aclip/0.1",
  "type": "error",
  "ok": false,
  "command": "note create",
  "error": {
    "code": "validation_error",
    "message": "invalid command usage"
  }
}
```

handler 抛异常会输出 `execution_error`。

## 退出码

- `0`: 成功或帮助输出。
- `1`: handler 执行异常。
- `2`: 参数、帮助路径或版本配置错误。

## Runtime helper

高级场景可以手动使用：

```ts
import { errorEnvelope, resultEnvelope } from "@oworker/aclip";
```

常规业务命令不需要手动包 envelope。
