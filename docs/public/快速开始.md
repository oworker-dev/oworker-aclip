# 快速开始

## 你会得到什么

ACLIP 不是一个新的 CLI 运行时。它是一组协议约束和参考 SDK，让你写出的 CLI 同时满足两类使用者：

- 人类用户继续使用自然命令、参数、`--help` 和退出码。
- Agent 可以读取结构化 manifest、分层帮助、认证需求、错误 envelope、诊断入口和 Skill 导出结果。

## Python 安装

```bash
pip install oworker-aclip
```

Python 包名是 `oworker-aclip`，import path 保持为 `aclip`：

```python
from aclip import AclipApp, run_cli, string_argument
```

最小示例：

```python
from aclip import AclipApp, run_cli, string_argument

app = AclipApp(
    name="notes",
    version="0.1.0",
    summary="A minimal notes CLI.",
    description="Create and inspect notes."
)

app.command(
    "create",
    summary="Create a note",
    description="Create a note with a title.",
    arguments=[string_argument("title", description="Note title")],
    examples=["notes create 'ship docs'"],
    handler=lambda title: {"created": True, "title": title},
)

if __name__ == "__main__":
    run_cli(app)
```

## TypeScript 安装

```bash
npm install @oworker/aclip
```

最小示例：

```ts
import { AclipApp, runCli, stringArgument } from "@oworker/aclip";

const app = new AclipApp({
  name: "notes",
  version: "0.1.0",
  summary: "A minimal notes CLI.",
  description: "Create and inspect notes."
});

app.command("create", {
  summary: "Create a note",
  description: "Create a note with a title.",
  arguments: [stringArgument("title", { description: "Note title" })],
  examples: ["notes create 'ship docs'"],
  handler: ({ title }) => ({ created: true, title })
});

runCli(app);
```

## 使用者命令体验

ACLIP SDK 会把声明式命令树翻译成自然 CLI：

```bash
notes --help
notes create "ship docs"
notes --aclip-help
notes --aclip-help create
```

`--help` 保留给普通 CLI 用户；ACLIP 结构化帮助通过协议专用入口暴露给 Agent。成功命令的 stdout 由 CLI 作者负责，SDK 不会强制把所有成功结果包成统一 JSON。错误结果则使用结构化 error envelope，便于 Agent 判断是否可重试、是否缺少认证、是否参数错误。
