# 打包与发布

## 打包目标

ACLIP 的打包层做三件事：

- 把 CLI app factory 解析成可运行 artifact。
- 在 artifact 旁生成 `.aclip.json` sidecar manifest。
- 把分发信息写入 manifest，便于 Agent 从 npm、PyPI 或本地 binary 反向理解 CLI。

## Python SDK 构建

```powershell
cd sdk\python
python -m pip install -e ".[dev]"
python -m build --sdist --wheel
python -m twine check dist\*
```

维护脚本：

```powershell
python scripts\publish.py check
```

`scripts/publish.py publish` 只发布 canonical 包 `oworker-aclip`，不会自动发布历史 `aclip` alias。

## TypeScript SDK 构建

```powershell
cd sdk\typescript
npm install
npm run build
npm publish --dry-run --access public
```

维护脚本：

```powershell
npm run release:check
```

## OWorker 发布入口

- npm package: `@oworker/aclip`
- PyPI package: `oworker-aclip`
- GitHub repository: `oworker-dev/oworker-aclip`

## 版本策略

本次迁移保留 Rendo 完整版 `0.3.4` 的协议与 SDK 语义，所以 OWorker 首发版本继续使用 `0.3.4`。后续版本建议：

- 只改文档或包元数据：patch。
- 扩展非破坏性 API：minor。
- 修改 schema 或运行时语义：先写决策记录，再发 major 或明确迁移说明。
