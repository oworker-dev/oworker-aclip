# 边界与兼容

## ACLIP 做什么

ACLIP 解决一次性 CLI 命令的 Agent 友好问题：

- 命令结构可发现。
- 参数和认证需求可理解。
- 帮助文本可渐进读取。
- 错误可机器判断。
- 环境问题可诊断。
- CLI 与命令知识可导出为 Skill。
- 打包产物可通过 sidecar manifest 被识别。

## ACLIP 不做什么

ACLIP 不标准化：

- 长期 live session。
- 浏览器自动化协议。
- REPL 交互。
- 多 Agent 编排。
- 服务市场排名。
- 从任意 CLI 自动推断完美协议描述。

这些能力可以在上层系统或相邻工具里实现，但不进入 ACLIP core。

## 兼容策略

OWorker 迁移版保留：

- 协议名 `aclip/0.1`。
- Python import path `aclip`。
- CLI 示例名 `aclip-demo-notes`。
- schema 文件名与语义。
- Python/TypeScript SDK 的核心 API。

变更项：

- npm 包名从 `@rendo-studio/aclip` 迁移到 `@oworker/aclip`。
- PyPI 包名从 `rendo-aclip` 迁移到 `oworker-aclip`。
- GitHub 入口迁移到 `oworker-dev/oworker-aclip`。

Rendo 原始文档完整保存在 `legacy/rendo-docs/`，用于追溯历史设计判断。
