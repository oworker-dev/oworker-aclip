# 项目概览

## 项目摘要

OWorker ACLIP 是面向 Agent 与 CLI 生态的命令行接口协议、schema 和 Python/TypeScript 参考 SDK。

## 项目介绍

ACLIP 的核心问题是：普通 CLI 对人类足够自然，但对 Agent 往往缺少稳定的结构化入口。Agent 需要知道有哪些命令、参数怎样填写、什么时候需要凭证、错误是否可重试、环境是否健康、有哪些操作指南可以复用。

OWorker ACLIP 提供三层能力：

- `schema/`: 机器可读协议契约。
- `sdk/python` 与 `sdk/typescript`: Python Click 和 TypeScript Commander 参考实现。
- `docs/` 与示例项目: 中文优先的使用、维护和发布说明。

本项目从 Rendo 归档版 `aclip` 无损迁移而来。历史设计文档完整保存在 `legacy/rendo-docs/`，当前公开口径以 `docs/` 为准。
